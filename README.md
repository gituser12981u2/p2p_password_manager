# P2P Password manager

A secure, peer-to-peer password manager written in Rust.
p2p password manager allows users to store, sync, and retrieve credentials across devices without centralized servers. All communication is peer-to-peer, encrypted end-to-end, and security focused.

**WARNING:** This project is still heavily under development.
